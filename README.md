# AI-Powered Content Composer

Build intelligent content with AI. An open-source Blazor web application that leverages GPT-3.5 Turbo to generate, customize, and transform content in real-time.

![A screenshot of AI-Powered Content Composer](ai-content-composer-gif.gif "AI-Powered Content Composer")

## Overview

The **AI-Powered Content Composer** is a modern web application that demonstrates how to seamlessly integrate OpenAI's GPT-3.5 Turbo with a rich, professional UI built using Syncfusion Blazor components. Whether you're writing blogs, emails, social media posts, or reports, this tool empowers you to create compelling content by simply specifying your topic and desired tone, format, and length.

## Features

- **Instant Content Generation**: Write about any topic with a single click
- **Tone Customization**: Choose from 8 distinct tones—Professional, Informal, Inspirational, Creative, Hilarious, Informational, Conversational, and Fictitious
- **Format Flexibility**: Generate content in multiple formats including paragraphs, emails, blog posts, bullet points, LinkedIn posts, reports, poems, reviews, and video scripts
- **Length Control**: Adjust content length to Short, Medium, or Long
- **Real-time Preview**: See a live preview of generated content before adding it to your document
- **In-Document Editing**: Built-in document editor with rephrase capabilities for continuous refinement
- **Seamless Integration**: Modify and add generated content directly into your document with one click

## Getting Started

### Clone the repository

```bash
git clone https://github.com/SyncfusionExamples/build-ai-powered-content-composer-in-blazor-using-openai-gpt.git
cd build-ai-powered-content-composer-in-blazor-using-openai-gpt
```

### Run with Visual Studio

1. Open the solution file using Visual Studio 2022 or later.
2. Restore the NuGet packages by rebuilding the solution.
3. Build the project to ensure there are no compilation errors.
4. Run the project.

### Run with .NET CLI

```bash
# Restore dependencies
dotnet restore

# Run the project
dotnet run
```
